Phar Lap P3 EXP Loader

The Phar Lap P3 EXP Loader imports flat-model 32-bit x86 P3 .EXP executables used by Phar Lap DOS extenders, including Free386.

The loader recognizes files with a P3 signature and a flat model field set to 1. Accepted files are loaded with the x86:LE:32:default language, with Borland C++ offered as the preferred compiler specification.

During import, the loader preserves the executable's encoded load addresses, including zero-based images. It creates memory blocks from the segment table when one is present, or reconstructs a flat image, stack, and heap layout from the P3 header fields.

Packed P3 images are decompressed during import. Runtime parameters, stack calculations, heap sizing, entry point information, and detected relocation or symbol tables are reported in the import log.
